# DevOps IaC & Automation Samples

This repository contains sample Infrastructure-as-Code (IaC) templates and automation scripts created for learning, practice, and demonstrating foundational DevOps skills.

## 📁 Contents
- **Terraform Samples**
  - EC2 provisioning
  - Security group configuration
- **Bash Automation Scripts**
  - Deployment automation
  - Log rotation script
- **Python Automation Utilities**
  - Cleanup script
  - Server health-check script

## 🚀 Purpose
- Show IaC knowledge
- Practice Git version control
- Demonstrate automation workflow understanding
- Build a strong DevOps portfolio
